자료 출처와 분석 기준
  • 정류장은 기존 전수 목록의 부산 ID를 기준으로 집계했습니다. 원천 자료는 국토교통부 전국 버스정류장 위치정보입니다. 목록에 공개 번호가 있는 경우 원본 5자리 문자열 그대로 표시합니다. CSV를 엑셀에서 불러올 때 정류장번호 열을 텍스트 형식으로 지정하면 선행 0이 유지됩니다. 타 지자체 ID 3건은 집계에서 제외했습니다.
  • 2D 지도의 도로와 건물 윤곽은 OpenStreetMap 기반 OpenFreeMap 공개 벡터 타일을 표시합니다. 벡터 지도를 사용할 수 없으면 OpenStreetMap 공개 이미지 타일을 표시합니다. 타일의 건물 윤곽은 정류장 주변 위치 확인에 사용합니다.
  • 표시 경계와 정류장 구·군 분류는 OpenStreetMap 부산광역시 하위 행정구역을 사용합니다. 구·군 경계 데이터 © OpenStreetMap contributors, ODbL 1.0. 2026.11.23 기준입니다. 경계에서 120 m 이내의 바깥 좌표는 가까운 구·군에 배치하고, 나머지는 ‘시 경계 밖’에 표시합니다. 초기 확대 범위는 육지 중심이며, 경계 데이터를 불러오지 못하면 통계청 SGIS 기반 기존 경계를 표시합니다.
  • 지형 추정은 Copernicus DEM GLO-30과 가까운 기준 정류장 30곳의 PVGIS ERA5 일사량·태양 위치를 사용한 1차 추정입니다. 정류장별 DSM 차폐는 약 90 m~15 km 범위에서 계산했습니다. 가까운 건물·가로수·승강장에 의한 음영은 상세 확인이 필요합니다.
  • 국토교통부 GIS건물통합정보 부산 원본(2026.11.09, 공공누리 제1유형)을 적용한 3D는 9,268개 정류장에서 볼 수 있습니다. 높이값을 사용할 수 있는 정류장 9,264곳의 발전량을 다시 계산했습니다. 건축물대장 높이를 우선 사용하고, 높이값이 없으면 층수×3.2m로 추정합니다. 건물 바닥 고도는 DSM 주변 표고로 추정합니다. 건물의 지붕 세부 형상과 안뜰은 단순화했습니다. 계산 반경 400m, 건물 표시 약 250m, 방향 간격 2°입니다. 브이월드 부산 자료 밖 건물, 근거리 수목과 승강장은 모델 범위에 포함되지 않습니다. 일부 건물 3D는 자료가 확보된 건물의 차폐를 보여주고, 연간·월간 발전량에는 지형 모델을 사용합니다. 지형 기반 3D는 정류장 주변 약 300m의 지형과 2° 간격의 지형 차폐를 사용합니다. 모든 모델에서 수목·승강장에 의한 근거리 음영은 반영하지 않습니다. 모든 발전량은 2021.12~2022.11의 과거 기상 조건, 정남향·경사 30°·높이 3 m·시스템 발전 효율 75%를 기본으로 가정했습니다. 사용자가 입력한 효율은 기본값 대비 비율로 발전량에 적용합니다. 겨울은 12~2월 90일 기준입니다.
  • 교량·고가철도 음영은 OpenStreetMap contributors · ODbL의 한국 지도 추출본(2026.11.24 KST)에서 교량으로 표시된 도로·철도·보행교를 사용합니다. 청록색은 상판의 추정 폭입니다. 교량 모델 데이터는 ODbL에 따라 제공합니다. 기본 밑면 높이는 도로교 6 m, 고가철도 8 m, 보행교 5 m로 추정합니다. 구조물 높이 보정은 정류장별로 저장되며, 시작·끝 높이로 경사를 만들고 차음벽이나 별도로 그린 역사·벽체도 계산에 넣습니다. 수동 추가 구조물은 직육면체 형태로 단순화합니다. 30분 간격의 월 대표일 직달광 변화로 기존 발전량을 보정하며, 버튼으로 교량 반영 전후를 비교할 수 있습니다.
  • 위치 보정은 같은 브라우저에 저장됩니다. 보정 위치에서 400 m 이내 건물 차폐를 다시 계산합니다. 지형 차폐는 원본 정류장의 모델을 사용하고, 패널 지면 높이는 주변 지형 격자에서 보간합니다. 보정 발전량은 월 대표일의 정남향 30° 패널에 입사하는 직달광 변화로 기존 월별 발전량을 보정한 추정치입니다. 위치·구조물을 보정한 정류장은 목록과 발전량 CSV에도 보정 결과를 표시합니다. 지형 차폐 CSV는 지형만 포함합니다.
  • 건물 윤곽 비교는 지도 위에 3D 모델의 GIS건물통합정보 외곽선을 표시합니다. 점선은 높이 미상, 주황색 면은 높이 또는 층수가 있는 경우이며, 범위 내 윤곽은 높이와 관계없이 표시합니다. 배경지도나 로드뷰의 시점과 원본 자료의 시점에 따라 차이가 날 수 있습니다.
  • 높이와 층수가 모두 미상인 건물은 지면에 윤곽만 표시하며 건물 차폐 계산에서 제외합니다.
  • 태양 경로는 선택한 월의 15일을 기준으로 00:00~23:30(KST)을 30분 단위로 표시합니다. 기존 시각별 차폐 자료만 있는 모형은 가장 가까운 기존 계산 시각의 차폐 여부를 사용합니다.
  • 배터리 용량 기본값은 972.8 Wh, 일일 소비량은 28 Wh/일입니다. 연속 흐림, 시간대별 충방전, 배터리 노화와 방전 제한은 반영하지 않습니다. 조회 결과 CSV는 정류장별 추가 손실과 월별 직접 입력값을 적용하기 전의 모델 값을 내보냅니다.
